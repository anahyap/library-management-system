# Library Management System

## Project Overview

The Library Management System is a web application designed to help users organize and manage a collection of books. The application will be developed using PHP and the Laravel framework while following the Model-View-Controller (MVC) design pattern.

This project is being developed for CSCI-2479 Advanced Web Programming at Columbus State Community College. It will demonstrate CRUD (Create, Read, Update, Delete) operations, user authentication, database management, and Agile development practices using GitHub.

## Project Objectives

- Develop a functional web application using PHP and Laravel.
- Apply the MVC design pattern to organize application logic.
- Implement CRUD operations for managing books.
- Provide secure user authentication and authorization.
- Create a responsive and user-friendly interface.
- Implement RESTful API endpoints.
- Use GitHub Issues and a Scrum/Kanban board to manage development.
- Test and deploy the completed application.

## Planned Application Features

### 1. User Authentication
Users will be able to register, log in, and log out. Authentication and authorization will help protect book management features.

### 2. Add Books
Authorized users will be able to add books to the collection by entering information such as the book title, author, ISBN, genre, and publication year.

### 3. View Books
Users will be able to browse the book collection and view details about individual books.

### 4. Update Books
Authorized users will be able to edit existing book information and save changes.

### 5. Delete Books
Authorized users will be able to remove books from the collection with a confirmation step to help prevent accidental deletion.

### 6. Search Functionality
Users will be able to search for books by title or author.

### 7. Responsive Design
The application will feature a user-friendly interface designed to work on desktop, tablet, and mobile devices.

### 8. RESTful API
The application will provide RESTful API endpoints for performing CRUD operations on book records.

### 9. Testing and Validation
The application will include input validation, error handling, unit tests, and appropriate mocks or stubs for testing dependencies.
